# Lista de tarefas com tema claro/escuro

Página onde dá para adicionar, concluir e remover tarefas. Tudo fica salvo no `localStorage`, então as tarefas continuam lá mesmo depois de fechar o navegador.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como rodar
É só abrir o arquivo `index.html` no navegador.

## Funcionalidades
- Adicionar tarefa (pelo botão ou apertando Enter)
- Marcar tarefa como concluída
- Remover tarefa
- Contador de tarefas concluídas
- Tema claro e escuro (a escolha também fica salva)
